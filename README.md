## Qué estoy construyendo

- **[iatodopyme.com](https://iatodopyme.com/)**: guías y comparativas sobre IA para pymes y autónomos en España. Incluye una [tabla de precios de herramientas de IA con calculadora de costes](https://iatodopyme.com/comparativas/precios-herramientas-ia/) que reviso cada mes con fuentes oficiales.
- **[duostudio.es](https://duostudio.es/)**: guías de compra de hogar, cocina y tecnología basadas en fichas oficiales y normativa de consumo.

Las dos son sitios estáticos (HTML, CSS y JavaScript sin frameworks) desplegados en un servidor propio.

## Herramientas propias (Python)

- Comprobador de sitio: enlaces internos, metadatos, sitemap y requisitos técnicos antes de publicar.
- Despliegue por SFTP que sube solo lo cambiado y verifica cada archivo publicado por hash.
- Avisos a buscadores con IndexNow y consultas a la API de Google Search Console.
- Revisión programada de precios con informe (launchd).
